# @hyoper/rn-transfer - React Native Transfer

## 🌐 About

A **high-performance** React Native library for **task-based file transfers**, supporting **downloads and uploads** with a reliable **queue-based architecture**. Manage transfer tasks with **progress tracking, cancellation, retries, and persistent state** across app sessions. Built with a simple, developer-friendly API. For full API documentation and usage examples, check out the 📖 API.
